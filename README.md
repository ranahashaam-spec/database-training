# BPO Wizard Database Training Document

A single-page, interactive training guide to recruiting databases and ATS/CRM platforms (10 chapters).

The whole site is one file: `index.html`. There is no build step.

## Publish with GitHub Pages

1. Create a new repository on GitHub (for example `database-training`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then **Save**.
5. After a minute or two the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Notes

- GitHub Pages sites are public. Do not include confidential company information.
- Fonts and the React library load from the internet, so viewers need a connection.
- Chapters have their own links, for example `.../#ch9` opens Chapter 9.
